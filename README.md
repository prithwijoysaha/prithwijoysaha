<details>
<summary><b>📦 BroadReach — Cross-border Logistics Aggregator</b></summary>

Built on AWS Serverless with SQS-driven async processing to handle shipment spikes without burning budget on idle compute.

`Node.js` `AWS Lambda` `SQS` `Redis` `MySQL` `Docker` `Microservices`
</details>
